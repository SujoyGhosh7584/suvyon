# Suvyon identity

The interwoven S represents conversations and actions joining in one workspace.
The lime dot is the point where an idea becomes a next step.

- `suvyon-mark.svg`: primary app icon.
- `suvyon-logo.svg`: horizontal logo for light backgrounds.
- `suvyon-symbol.svg`: monochrome symbol on a transparent background.

Palette: Ink `#101629`, Signal blue `#5264F5`, Periwinkle `#7590FF`, Lime
`#D4FA75`, Canvas `#F5F6FA`. Keep one dot diameter clear around the mark.
Use the app mark at 24px or larger. SVG assets scale without losing quality.
The horizontal wordmark uses system sans-serif text; convert text to outlines
for print workflows that require font-independent reproduction.

Runtime copies are in `frontend/public/brand`; the favicon uses the primary mark.

# Sujoy Ghosh Portfolio

A dependency-free, responsive portfolio for GenAI, AI engineering, and agentic AI roles.

## Preview locally

From the repository root:

```powershell
python -m http.server 4173 --directory portfolio
```

Open `http://127.0.0.1:4173`.

## Deploy to Vercel

1. Create a new Vercel project from this repository.
2. Set **Root Directory** to `portfolio`.
3. Leave the framework preset as **Other** and the build command empty.
4. Deploy.

## Content sources

Portfolio claims are based on the verified résumé and the Suvyon repository. The résumé PDF is bundled under `portfolio/assets` so the download remains stable when the portfolio is deployed independently.
